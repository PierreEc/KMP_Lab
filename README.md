# KMP_Lab

### Copilot skills

After cloning the project, install [APM](https://github.com/microsoft/apm) and run
`apm install` from the project root to install the pinned skills declared in
`apm.yml`. The Android skills apply to Android-specific work; the project also
includes Kotlin/Compose Multiplatform, architecture, DDD, and TDD skills.

The generated `apm_modules/` and `.agents/skills/` directories are ignored by
Git. Keep `apm.yml` and `apm.lock.yaml` versioned so others can install the
same skills. If distributing generated skill copies, retain their upstream
license and notice files; APM reinstallation can remove manually added copies.
